ABOUT THE WORK / 作品說明

不可見的，正在發生。

「游離」是一件生成式互動藝術作品。它將字元化為塵埃，通過分組放射線簇演算法，在黑色空間中不斷生成、擴散與消散。

向左移動，字元被牽引並收束為細流；向右移動，字元向外展開成扇形。滑動越快，流場越強；停下後，擾動逐漸消退。滑鼠懸停帶來排斥與偏移；觸控按住時，字元在指尖附近輕微聚攏並持續迴旋；輕點引發一次放射性的爆散；滾動讓流場短暫地卷動。日常螢幕行為，成為這片數位空間的微小氣候。

這裡沒有等待解讀的結構化數據，只有轉瞬即逝的符號、被擾動的軌跡，以及疊加後逐漸稀薄的透明度。資訊觸發、擴散、消散，在你的參與中反覆發生。

當螢幕恢復平靜，我們是否仍能感知，那些持續無序的資訊溢散？

操作：向左聚流 / 向右散流 / 點擊爆散 / 滾動湧流
觸控螢幕：按住約 0.3 秒旋流（放開不爆散） / 左右拖動聚散 / 上下拖動湧流 / 輕觸爆散
快捷鍵：SPACE 暫停 · F 全螢幕 · H 沉浸 · ESC 退出全螢幕 / 沉浸
